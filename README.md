## 平台是怎么靠 IP 查出你的店有关联的

三条线：店铺资质验证、IP 地址追踪、设备指纹识别。资质这层（注册人、收款账户、公司信息）改动成本高，多数卖家也不会去碰；真正让卖家“莫名”翻车的，往往是后两条。

最常见的翻车方式很朴素：公司里几台电脑共用一条宽带，所有店铺的登录都从同一个公网 IP 出去。平台不需要什么复杂算法，看一眼登录记录就够了。反过来也一样——就算 IP 分开了，如果几个店铺环境用的是同一套浏览器指纹（同样的硬件序列号、同样的浏览器版本和系统版本），照样会被连起来。

所以正确姿势是两层同时隔离：每家店一个独立 IP，加一套独立的浏览器环境。少任何一层，都有被串起来的风险。

## 四类主流方案，真实成本差多少

目前能落地的方案就四类：自建海外云服务器、防检测浏览器、专业 IP 供应商、住宅 IP VPN 服务。表面月租看着都差不多，真实差距藏在流量费和 IP 费这两个隐藏项里。

| 方案 | 参考成本 | 优点 | 主要限制 | 适合谁 |
| --- | --- | --- | --- | --- |
| 海外云服务器自建 | AWS 1核0.5G 约 $3.87/月，公网 IP 另收约 $3.6/月；DigitalOcean $4/月送 2 个 IP；阿里云 ¥3.8/月起送 1 个 IP | 完全控制，可扩展 | 要自己搭建运维，流量另计费 | 有技术能力的团队 |
| 防检测浏览器 | 浏览器月费 + IP 费分开算 | 一台电脑模拟出多套独立硬件环境 | 除少数自带 IP 的产品外，IP 需另配 | 非技术卖家 |
| 专业 IP 供应商 | 静态住宅 IP 约 $5/月/IP（如 IPFoxy） | 灵活，有专业支持 | 买完还得配进浏览器或工具里才能用 | 已有固定工作流的卖家 |
| 带住宅 IP 的 VPN 服务 | 通常高于机房 IP | 平台信任度高，连接稳定 | 要认准住宅 IP，普通动态 VPN 用不了 | 想开箱即用的卖家 |

以上均为月付价。云服务器方案最容易在两处超预算。一处是 IP 费：AWS 不送免费公网 IP，按 $0.005/小时计费，一个月约 $3.6，而且 AWS 已宣布对每个 IPv4 地址收取每月 $0.5–5 的费用。另一处是流量：AWS 新加坡流量 $0.12/GB，DigitalOcean 前 500GB 免费、超出 $0.01/GB，阿里云 ¥6.75/10GB。以月流量 8GB 为分界线，低于它 AWS 最省，高于它 DigitalOcean 反超。

问题是 8GB 这个坎很容易破。上传产品图和视频动辄几百 MB，做直播电商每秒几 MB 的码率，一个小时就冲过 8GB。所以动手自建之前，先按自己的业务形态把这笔账算完——高流量卖家未必划算。顺带一个选配冷知识：AWS 的 2 核 0.5G 配置反而比 1 核 0.5G 便宜。

防检测浏览器补的是另一半。它的原理是在同一台电脑上模拟出多套互相独立的环境——IP、浏览器版本、操作系统版本、硬件序列号各不相同。紫鸟这类产品内置了 IP 资源，开箱即用；AdsPower 则要自己接一家 IP 供应商。对非技术卖家来说，它把“环境隔离”这块解决了，IP 那一半仍然要单独解决。

住宅 IP 是几类里平台信任度最高的一种。它由 ISP 分配给真实的家庭用户，在平台侧看起来就是一次普通的家庭宽带登录，信任评分高、地理定位准。这里要专门排个雷：传统 VPN 用不了。大多数 VPN 是动态 IP 分配，每次重连换一个新地址，频繁换 IP 在平台眼里就是典型的异常行为，搞不好直接把店搭进去。

## 常见问题

### 普通翻墙 VPN 能当店铺 IP 用吗？

不能。大多数 VPN 是动态 IP，每次重连换新地址，频繁更换会被平台判定为异常行为，风险比不用还大。店铺需要的是固定不变的静态 IP。

### 一个 IP 能带几家店？

一家。每个店铺绑定专属 IP，多店共用一个 IP 等于自己把关联证据递给平台。这里的钱不能省。

### 用了代理 IP，平台会检测出来吗？

合规的住宅 IP 和真实家庭用户的流量特征一致，平台看到的就是一次正常的家庭宽带登录。真正会被识别的是两样东西：被大量滥用过的 IP，以及 IP、设备指纹、行为习惯互相矛盾的账号。选干净的 IP、固定环境使用，比纠结“会不会被检测”有用得多。

### IP 被封了怎么办？

先别在原环境反复重试，那只会加重风控记录。联系 IP 服务商换新 IP，换之前把新 IP 检测一遍；同时查一下封禁原因——如果问题出在设备指纹上，单换 IP 救不回来，得连环境一起换。
